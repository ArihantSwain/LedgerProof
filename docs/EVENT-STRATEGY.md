## Priority decision

1. **Core:** prove the CREAO investigator, exact cash math, source drilldown, review, recovery, and a runnable judge flow.
2. **Primary narrative:** a receivables controller assistant for Hyphenate; a production-minded finance agent for Microsoft; an AI-first receivables investigation for CREAO.
3. **Backend proof:** actually deploy and demonstrate Convex, with live state and durable execution rather than source-only claims.
4. **Conditional:** traceable Claude use; defensible CRS sandbox use; authentic test Coinbase Payment Agents flow.
5. **New paths:** evaluate Figma workflow and Factory runtime evaluation worker only when their real work exists. Do not rewrite the product to enter every track.

CREAO's event pack requires a hosted core agent, its ID/run share link, and visible execution. AI-First Disruptor is the clearest proposed fit. One-Person Company would need an actual coordinated organization of role agents, which is not implemented. Team Empowerment could fit a proven preparer/reviewer workflow, but track selection should follow the actual live product. Local rehearsal is engineering support, not the sponsor entry.
